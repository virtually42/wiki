# Tech Glossary

Shared vocabulary used across the wiki. Each entry is a section
(not a separate file) per `meta/schema.md` §"glossary-entry".

This page is a **stub** — populated on demand as terms accumulate
genuine ambiguity across pages. The first useful entries will be
terms that already appear in multiple Layer-2 pages with subtly
different framings (e.g. *normative* vs *descriptive*,
*executable encoding* vs *declarative encoding*, *Layer 2* vs
*Layer 3*).

## How to use

- When mentioning a term that has an entry here, link to it as
  `[[tech/glossary#term-anchor]]`.
- When adding an entry, prefer a one-paragraph definition plus a
  link to the page where the term is *normatively* defined (if any).
