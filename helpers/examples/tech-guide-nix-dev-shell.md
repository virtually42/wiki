# Guide: Nix Dev Shell for Scala Projects

## Prerequisites

- NixOS or Nix installed with flakes enabled
- A `flake.nix` at the project root

## Basic flake.nix for Scala 3 + Mill

```nix
{
  inputs = {
    nixpkgs.url = "github:NixOS/nixpkgs/nixos-unstable";
    flake-utils.url = "github:numtide/flake-utils";
  };

  outputs = { self, nixpkgs, flake-utils }:
    flake-utils.lib.eachDefaultSystem (system:
      let
        pkgs = nixpkgs.legacyPackages.${system};
      in {
        devShells.default = pkgs.mkShell {
          buildInputs = with pkgs; [
            jdk21
            mill
            metals
            scalafmt
          ];

          shellHook = ''
            export JAVA_HOME=${pkgs.jdk21}
          '';
        };
      });
}
```

## For Scala Native projects

Add native toolchain dependencies:

```nix
buildInputs = with pkgs; [
  jdk21
  mill
  metals
  scalafmt
  # Scala Native requirements
  clang
  llvmPackages.libcxxabi
  s2n-tls
  # Project-specific C libraries
  wayland
  wayland-protocols
  wlroots
  libxkbcommon
  pixman
];
```

## For projects with PostgreSQL

Add PostgreSQL for local development and testing:

```nix
buildInputs = with pkgs; [
  jdk21
  mill
  metals
  postgresql_16
];

shellHook = ''
  export PGDATA=$PWD/.pgdata
  export PGHOST=$PWD/.pgdata
  if [ ! -d "$PGDATA" ]; then
    initdb --no-locale --encoding=UTF-8
    echo "unix_socket_directories = '$PGDATA'" >> $PGDATA/postgresql.conf
  fi
'';
```

## Variations

### With direnv

Create `.envrc`:
```
use flake
```

This auto-activates the dev shell when you enter the directory.

### With Cachix

Add a binary cache to avoid rebuilding:

```nix
nixConfig = {
  extra-substituters = [ "https://your-cache.cachix.org" ];
  extra-trusted-public-keys = [ "your-cache.cachix.org-1:..." ];
};
```

## Troubleshooting

### Mill can't find Java

Ensure `JAVA_HOME` is set in `shellHook`. Check with `echo $JAVA_HOME`.

### Scala Native linking errors

Verify that all required C libraries are in `buildInputs`. Use `pkg-config --libs <library>` to check availability.

### Metals not connecting

Restart the Metals server. Ensure `.bsp/` is generated by running `mill mill.bsp.BSP/install`.
